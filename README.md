To-Do List System

A To-Do List Web Application based on Python Flask and SQLite.  
This is a full-stack beginner project demonstrating CRUD operations.

✨ Features
Add Tasks: Create tasks with an optional due date.
Complete Tasks: Mark tasks as done, shown with a strike-through.
Delete Tasks: Remove tasks from the database.
Filter: Filter tasks by status (All, Todo, Done) and due date.
Statistics: Real-time count of pending tasks.

🛠️ Tech Stack
Backend: Python 3, Flask
Database: SQLite3
Frontend: HTML, Jinja2, Simple.css
